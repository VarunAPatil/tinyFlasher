# tinyFlasher

Bare-metal ESP32-S3 firmware with a custom native USB ROM flasher and serial monitor.

It builds a ROM-bootable image and flashes it through the chip's ROM protocol, without ESP-IDF.

Includes startup code, a linker script, an image packer, a flashing utility, and a serial monitor.
